:::note[С чего начать]
Это переработанное издание с DevOps-ядром. Основной маршрут начинается с Linux, сетей и Git, а затем переходит к Python, SQL, контейнерам, CI/CD, IaC, Kubernetes и SRE. Frontend и Node.js оставлены как прикладной слой для тех, кто обслуживает такие приложения, но больше не являются обязательным входом в DevOps.
:::

## Структура учебника

0. **Git — всё-всё-всё** — устройство изнутри, ветвление, merge/rebase со схемами, воркфлоу, продвинутые приёмы.
1. **JS Core** — прикладной раздел для Node.js и frontend-маршрута, не обязательный для DevOps.
2. **TypeScript** — система типов, дженерики, условные и mapped-типы, branded types.
2а. **CSS Core** — каскад, специфичность, бокс-модель, Flexbox, Grid, позиционирование, анимации, адаптив.
2б. **CSS-фреймворки и инструменты** — Sass/PostCSS, Bootstrap, UnoCSS/daisyUI, CSS-in-JS, MUI/Chakra/Mantine.
3. **React** — рендеринг, хуки в деталях, состояние, формы, роутер, тесты.
4. **Next.js** — стратегии рендеринга, RSC, кэширование, Server Actions, Edge.
5. **Стили, a11y, Performance** — Tailwind, Radix, современный CSS, Core Web Vitals.
6. **Node.js** — libuv, стримы, многопоточность, ESM, монорепозитории и DX, продакшен-эксплуатация.
7. **NestJS и API** — DI-контейнер, жизненный цикл запроса, REST, realtime WebSocket/SSE, GraphQL, gRPC, очереди и outbox.
8. **Данные** — PostgreSQL (моделирование, индексы, транзакции, бэкапы), ORM, Redis.
9. **Безопасность и тестирование** — JWT/OAuth, OWASP, пирамида тестов, Playwright.
10. **Linux и Docker** — bash, systemd, сети, контейнеры под капотом, supply-chain security.
11. **Kubernetes и CI/CD** — манифесты, Helm, GitHub Actions, GitOps.
12. **IaC, деплой, наблюдаемость** — Terraform, Ansible, секреты, Nginx/TLS, логи/метрики/трейсы, инциденты.
13. **Облака, System Design, AI** — AWS, масштабирование, паттерны устойчивости.

Плюс **стабильный стек** с правилами выбора и замены технологий, литература и ресурсы, углубление с первоисточниками, [глоссарий](/appendix/glossary/) и [сводные вопросы на собеседование](/appendix/interview-questions/) — инструменты для повторения пройденного.

:::tip[Золотое правило]
Теория мертва без практики. Каждая изученная глава должна найти отражение в pet-проекте или opensource-контрибуции. Выполняй раздел **Практика** — не переходи дальше, пока результат не работает.
:::

:::note[Окружение]
Команды проверяются на Linux; для лабораторий рекомендуем Debian/Ubuntu LTS или контейнеризированную среду. Arch Linux и Omarchy остаются опциональными вариантами рабочего места, а не требованием к читателю.
:::
